# Kubernetes Production Lab

Production-oriented Kubernetes engineering laboratory.

## Scope

- kubeadm
- containerd
- CNI
- Scheduling
- Services
- Ingress
- Storage
- RBAC
- NetworkPolicy
- Secrets
- Prometheus

- CrashLoopBackOff

- Node NotReady
- DNS failure
- CNI failure
- Service unreachable
- PVC Pending
- OOMKilled
- CPU throttling
- Kubelet failure
- Control Plane failure
