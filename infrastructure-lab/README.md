# Infrastructure Lab

生产级基础设施工程实验室。

## 项目定位

这是整个技术作品集的基础层。

重点不是简单安装软件，而是研究：

- 部署
- 高可用
- 数据持久化
- 性能
- 监控
- 故障排查
- 自动化
- 安全
- 灾难恢复
- 容量规划
