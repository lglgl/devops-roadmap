# DevSecOps Pipeline

Security integrated into the software delivery lifecycle.

## Pipeline

Developer
→ GitHub
→ Jenkins / GitLab CI
→ SAST
→ Dependency Scan
→ Secret Scan
→ IaC Scan
→ Container Scan
→ Policy Check
→ Deploy

## Security Controls

- SAST
- SCA
- Secret scanning
- Container vulnerability scanning
- Terraform / IaC scanning
- Kubernetes policy enforcement
- Security gates
