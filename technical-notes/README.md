# Technical Notes

## 写作原则

不要只写：

> 什么是 Kubernetes？

而应该写：

> Kubernetes 某个生产问题是如何发现、定位、解决和预防的。

## 标准文章结构

1. Problem
2. Background
3. Architecture
4. Implementation
5. Failure
6. Diagnosis
7. Root Cause
8. Solution
9. Prevention
10. Lessons Learned
